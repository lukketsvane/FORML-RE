# Blindpar-gransking

Åpne review.html lokalt i nettlesar eller start:

    python -m http.server 8765

frå research/nordisk-designforsking og gå til http://localhost:8765/results/review.html.

Bruk ei eiga kodar-ID for kvar forskar, kod uavhengig og eksporter JSON/CSV.
Grunngje vurderingar med sidetal i begge fulltekstar. Eit markert svar utan fulltekst er ikkje vitskapleg dokumentasjon.
Ingen data vert sendt til tredjepart. Berre DOI-lenkjer vert opna etter klikk.

Merk: Utvalet er semantisk målretta, ikkje representativt. Resultata kan nyttast til instrumentvalidering, ikkje estimat over heile faget.
