# stil-referansar — stilreferansar til `teikne-sider.py`

Legg **3–6 referansebilete** her (`.jpg`/`.jpeg`/`.png`/`.webp`). Dette er
penn-og-blekk-teikningane i Andreas Töpfer / Armen Avanessian-stilen som
`teikne-sider.py` sender med på kvart `images.edit`-kall som stilreferanse
(t.d. `IMG_4026.jpeg`).

Bileta du la ved i chatten kan ikkje skrivast til disk frå samtalen av seg
sjølv — difor må dei leggjast her manuelt (lokalt, eller commitast hit).

Råd:
- bruk reine, høgoppløyste sider (kvit grunn, svart kontur, lite handskrift);
- 3–5 stykke gjev modellen nok å lese stilen av utan å bli forvirra;
- desse filene er med vilje **ikkje** sjekka inn (sjå `.gitignore`) — dei kan
  vere opphavsrettsverna; hald dei lokalt.
